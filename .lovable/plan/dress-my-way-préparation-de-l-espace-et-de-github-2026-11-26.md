# Dress My Way — Préparation de l'espace et de GitHub

## Ce qui existe déjà
- L'espace du projet est déjà créé et initialisé : il contient le modèle de départ standard, sans aucune page, fonctionnalité ni base de données ajoutée.
- Aucun service backend n'est activé. Rien n'est publié.

## Ce que je peux faire en mode Plan
- Lire le projet et répondre à vos questions.
- Rédiger ce plan.
- Je ne peux ni modifier le code, ni renommer le projet, ni connecter GitHub depuis le chat.

## Ce que vous faites vous-même (aucun code généré)
1. Renommer le projet en « Dress My Way » : cliquez sur le nom du projet en haut à gauche, puis Renommer.
2. Connecter GitHub : Paramètres du projet → Git → Connecter GitHub, puis autorisez l'application Lovable GitHub sur votre compte ou organisation.
3. Lovable crée alors un nouveau dépôt privé et pousse le code de départ du modèle. Lovable ne peut pas se lier à un dépôt déjà existant.

## À savoir pour « GitHub = source officielle »
- La synchronisation est bidirectionnelle sur une seule branche (par défaut `main`).
- Ce que vous poussez sur cette branche apparaît dans l'aperçu Lovable.
- Évitez les force-push et les rebases sur la branche synchronisée : ils remplacent le travail côté Lovable.

## Ce que je ne ferai pas
- Aucun code, aucune page, aucun composant, aucune base de données, aucun package, aucune publication.
- Si vous approuvez ce plan, je n'écrirai rien dans l'application : il n'y a rien à construire.
