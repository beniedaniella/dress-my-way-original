# Dress My Way

Je souhaite créer un nouveau projet nommé Dress My Way.



Pour cette première étape, mes seuls objectifs sont les suivants :



1. Créer et initialiser l'espace de travail du projet Dress My Way.

2. Rendre disponible l'intégration GitHub afin que je puisse associer le projet à mon compte GitHub.

3. Ne générer et ne modifier aucun code de l'application.

4. Ne créer aucune page, aucun composant, aucune fonctionnalité ni aucune structure de base de données.

5. Ne pas activer Supabase ni aucun autre service backend.

6. Ne pas installer de packages, ne rien publier et ne rien déployer.



Contexte important :

GitHub sera la source officielle du code. Lovable sera principalement utilisé comme environnement de visualisation et de prévisualisation du projet.



Consignes impératives :



- Rester exclusivement en mode Plan.

- Ne pas passer en mode Build.

- Ne pas exécuter de plan de développement.

- Ne réaliser aucune opération qui pourrait générer ou modifier du code.

- Ne rien entreprendre au-delà de la création de l'espace de travail et de la préparation de l'intégration GitHub.



Avant toute action, indique clairement ce qui peut réellement être effectué en mode Plan, sans passer en mode Build.
